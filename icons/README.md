# Icons

This directory contains the icon assets used throughout the APHI user interface.

## Conventions
- **Format**: All icons should be in PNG or SVG format.
- **Sizes**: For ribbon buttons, provide both 16x16 and 32x32 pixel versions (e.g., `Analyze16.png`, `Analyze32.png`).
- **Style**: Match the flat, modern aesthetic of ArcGIS Pro's native icons. Use standard Esri colors for states (Green for Success/Good, Yellow for Warning, Red for Error).
- **Dockpane**: Icons used within the WPF dockpane should ideally be vector paths defined in XAML dictionaries for infinite scalability, but PNG fallbacks can be stored here.
