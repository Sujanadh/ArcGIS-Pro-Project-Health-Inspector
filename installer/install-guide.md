# Installation Guide

Follow these steps to install the ArcGIS Pro Project Health Inspector (APHI).

## Prerequisites
- ArcGIS Pro 3.3 or higher installed.
- Windows 10 or 11.
- .NET 8 Desktop Runtime.

## Steps

1. **Download the Add-in:**
   Navigate to the [Releases page](../../releases) on GitHub and download the latest `APHI.esriAddinX` file.

2. **Run the Installer:**
   Double-click the downloaded `APHI.esriAddinX` file. This will open the Esri ArcGIS Add-In Installation Utility.

3. **Confirm Installation:**
   In the utility window, review the add-in details (Name, Version, Author) and click the **Install Add-In** button.

4. **Start ArcGIS Pro:**
   Open ArcGIS Pro.

5. **Verify Installation:**
   - Open any project.
   - Look for the new **Health Inspector** tab on the ribbon.
   - Click the **Dashboard** button to open the dockpane.

6. **Updating:**
   To update to a newer version, simply download the new `.esriAddinX` file and double-click it. It will overwrite the existing installation.

## Uninstallation
1. In ArcGIS Pro, go to the **Project** tab.
2. Click on **Add-In Manager**.
3. Locate the "APHI" add-in in the list.
4. Click **Delete this Add-In**.
5. Restart ArcGIS Pro.
