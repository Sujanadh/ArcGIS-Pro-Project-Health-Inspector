# Contributing to APHI

First off, thank you for considering contributing to the ArcGIS Pro Project Health Inspector (APHI)!

## Code of Conduct
By participating in this project, you are expected to uphold our [Code of Conduct](CODE_OF_CONDUCT.md).

## How Can I Contribute?

### Reporting Bugs
Bugs are tracked as GitHub issues. Use the Bug Report template provided in the issue tracker. Include as much detail as possible:
* ArcGIS Pro version
* OS version
* Steps to reproduce the behavior
* Expected vs. actual behavior

### Suggesting Enhancements
Enhancement suggestions are tracked as GitHub issues. Use the Feature Request template to suggest a new feature or improvement.

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code follows the coding standards outlined in the [Developer Guide](docs/developer-guide.md).
6. Open a Pull Request using the provided PR template.

## Coding Standards
* We follow standard C# coding conventions.
* Use clear, descriptive variable and method names.
* Comment complex logic and public APIs.
* Keep classes focused on a single responsibility.

Thank you for contributing!
