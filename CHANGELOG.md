# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-04

### Added
- Initial release of the ArcGIS Pro Project Health Inspector (APHI).
- Analysis Engine with 20 distinct project health analyzers.
- Dockpane UI for viewing analysis results and health score.
- Auto-Fix capabilities for eligible issues.
- Report generation in HTML, CSV, JSON, and Text formats.
- Configuration settings to customize analysis thresholds.
- Comprehensive documentation and developer guides.
