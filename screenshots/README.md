# Screenshots

This directory stores screenshots used in the main `README.md` and other documentation files.

## Guidelines for Screenshots

1. **Resolution**: Keep screenshots clear. If scaling down, ensure text remains readable.
2. **Focus**: Crop screenshots to the relevant area (e.g., just the dockpane or a specific dialog) rather than capturing the entire desktop, unless showing overall context.
3. **Theme**: Take screenshots using the default ArcGIS Pro Light theme for consistency, unless specifically demonstrating Dark mode compatibility.
4. **Naming**: Use descriptive lowercase names with hyphens (e.g., `dockpane-results.png`, `options-dialog.png`).

To update the main README image, replace `dashboard.png` with the new capture.
